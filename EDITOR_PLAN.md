# Website editing interface

Implemented in this rebuild: a discreet homepage owner entry, server-side password authentication, structured About/home and technical-skills editing, Markdown editing for projects/posts/experience/certificates, new project/post drafts, text previews, GitHub revision history and restoration, and concurrent-edit protection.

See [EDITOR_SETUP.md](EDITOR_SETUP.md) for private deployment settings and operating instructions. The server remains locked until configured. File uploads and a visual layout designer are not part of this release.
